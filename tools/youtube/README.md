# YouTube для RG40XX H (Knulli)

YouTube без рекламы в разделе «Порты»: подборки по темам, поиск, история с продолжением просмотра, пропуск спонсорских вставок (SponsorBlock) и скачивание для просмотра без сети.

## Установка с Mac

```sh
tools/youtube/install.sh 192.168.2.173
```

| Файл | Куда ставится |
| --- | --- |
| `youtube_app.py` | `/userdata/roms/ports/YouTube/` |
| `YouTube.sh` | `/userdata/roms/ports/` |

Установщик сохраняет загрузки, историю (`state.json`), миниатюры (`cache/`) и `font.ttf`, заранее готовит yt-dlp и обновляет описание в `gamelist.xml` «Портов» (если не запущена игра).

## Управление

**Списки:** L1/R1 — вкладки (Главная, Поиск, История, Загрузки), крестовина — выбор, влево/вправо на Главной — тема, L2/R2 — на страницу, A — меню ролика, X — скачать (на Поиске — новый поиск), Y — обновить / удалить, Select — поиск, Start — меню приложения, B — выход (с подтверждением), Menu — выход сразу.

**Клавиатура:** A — ввод, X — стереть, R1 — пробел, Y — RU/EN, Start — найти, B — закрыть. Вверху — последние запросы.

**Плеер:** A — пауза, влево/вправо — 10 с (удержание — перемотка), L1/R1 — минута, L2/R2 — 5 с, вверх/вниз — громкость, X — время, Y — скорость (1 / 1.25 / 1.5 / 2 / 0.75), Select — с начала, B или Menu — выход. Позиция запоминается, ролик продолжается с неё.

## Как устроено

- **yt-dlp** на приставке — сжатый zipapp, один его запуск занимает ~6 с. Приложение берёт самую новую версию из `lib/yt-dlp.zipapp`, `/userdata/system/bin/yt-dlp` и `/usr/bin/yt-dlp`, один раз на версию пересобирает её в `lib/yt_dlp-<версия>.pyz` (несжатый zip с готовым байткодом, ~15 с) и импортирует в свой процесс. Ссылка на видео получается за 3–4 с.
- **Поток:** без JS-движка и PO-токенов YouTube отдаёт только формат 18 (360p, H.264 + AAC) и только клиенту `android`; у `android_vr` ссылки отвечают 403. Поэтому качество 360p, трансляции идут через HLS.
- **Плеер:** mpv с `--vo=sdl` через SDL-драйвер `mali` (fbdev). У mpv на Knulli нет Lua и ввода с геймпада, поэтому приложение само читает геймпад через evdev и управляет mpv по IPC (`/tmp/rg-youtube-mpv.sock`). Так же сделан SponsorBlock: на сегменте спонсора, саморекламы или просьбы подписаться mpv перематывается дальше и показывает, что пропущено.
- **Загрузки** — тот же yt-dlp в отдельном процессе, с `--sponsorblock-remove` (вставки вырезаются из файла). Звук извлекается в m4a.
- **Шрифт** без эмодзи и значков, поэтому они вычищаются из названий, а иконки нарисованы.
- **Обновление yt-dlp:** Start → «Обновить yt-dlp» скачивает последний релиз с GitHub в `lib/yt-dlp.zipapp`, после чего приложение перезапускается и пересобирает библиотеку.

Журналы: `/tmp/youtube.log` (приложение), `/tmp/youtube-mpv.log` (последний запуск mpv).
