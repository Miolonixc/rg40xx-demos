# 3D-порты для Anbernic RG40XX H (rg40xx-h)

Источник — официальный каталог PortMaster. Скачиваются только порт-пакеты;
игры с пометкой **нужны файлы** требуют данные из вашей собственной копии.

Автоматизация: `python scripts/install_3d_ports.py --download DIR` (только бесплатные),
`--all` (добавить игры, которым нужны свои файлы), `--install` (поставить на приставку по SSH).

## Установка

1. Поставьте PortMaster из `Apps`/`Tools` прошивки (или с portmaster.games).
2. Запустите PortMaster → нужная игра → Install. Либо скачайте zip из таблицы и положите в папку портов:
   - muOS: `/mnt/mmc/ROMS/Ports`
   - Knulli: `/userdata/roms/ports`
3. Для игр «нужны файлы» скопируйте данные в папку порта (`Ports/<Игра>/`) — что именно, написано в README порта.
4. Перезапустите EmulationStation / обновите список игр.

## 3D через эмуляцию

Проще и быстрее, чем порты, для старой 3D-классики (образы — со своих дисков):

- **PS1** — DuckStation: весь 3D-каталог, отлично идёт.
- **N64** — mupen64plus: большинство игр.
- **Dreamcast** — Flycast: многие, кроме тяжёлых.
- **PSP** — PPSSPP: простые 3D, тяжёлые не пойдут.
